# 🐍 Fundamentos de Python - Google Colab

Este repositório reúne uma série de atividades desenvolvidas no **Google Colab** com o objetivo de praticar os conceitos fundamentais da linguagem **Python**.

Ao longo dos exercícios foram explorados os principais recursos da linguagem, como declaração de variáveis, operações matemáticas, formatação de saída de dados e estruturas de dados, proporcionando uma base sólida para o desenvolvimento de programas mais complexos.

## 🎯 Objetivos do Projeto

* Aprender a sintaxe básica da linguagem Python.
* Desenvolver o raciocínio lógico por meio de exercícios práticos.
* Compreender os diferentes tipos de dados.
* Praticar operações matemáticas e manipulação de informações.
* Conhecer as principais estruturas de dados da linguagem.

---

## 📚 Atividades Desenvolvidas

### 🔹 Atividade 1 – Variáveis e Impressão de Dados

Criação de variáveis para armazenar informações pessoais, como nome, idade e profissão, exibindo os valores utilizando a função `print()`.

**Conceitos praticados:**

* Variáveis
* Tipos de dados
* Saída de dados (`print`)

---

### 🔹 Atividade 2 – Cadastro de Produto

Programa que armazena informações de um produto, incluindo nome, marca e preço, utilizando formatação de valores monetários com *f-string*.

**Conceitos praticados:**

* Strings
* Números decimais (`float`)
* Formatação de texto
* f-strings

---

### 🔹 Atividade 3 – Operações Matemáticas

Desenvolvimento de uma calculadora simples realizando:

* Soma
* Subtração
* Multiplicação
* Divisão

**Conceitos praticados:**

* Operadores aritméticos
* Variáveis
* Cálculos matemáticos

---

### 🔹 Atividade 4 – Operadores Aritméticos

Ampliação da calculadora incluindo o operador de potenciação e diferentes formas de apresentação dos resultados.

**Conceitos praticados:**

* Potenciação (`**`)
* Operações matemáticas
* Organização da saída de dados

---

### 🔹 Atividade 5 – Revisão das Operações Matemáticas

Exercício de revisão reforçando o uso dos operadores aritméticos e da impressão organizada dos resultados.

**Conceitos praticados:**

* Operadores matemáticos
* Variáveis
* Estrutura básica de programas

---

### 🔹 Atividade 6 – Listas, Tuplas e Dicionários

Introdução às principais estruturas de dados do Python utilizando exemplos relacionados a disciplinas, notas e informações de um aluno.

**Conceitos praticados:**

* Listas (`list`)
* Tuplas (`tuple`)
* Dicionários (`dict`)
* Manipulação de coleções

---

### 🔹 Atividade 7 – Estruturas de Dados Aplicadas

Utilização de listas, tuplas e dicionários para armazenar informações de um veículo, seus acessórios e especificações.

**Conceitos praticados:**

* Estruturas de dados
* Organização de informações
* Coleções em Python

---

### 🔹 Atividade 8 – Criação de Lista

Exercício introdutório para criação e armazenamento de categorias em uma lista.

**Conceitos praticados:**

* Listas
* Armazenamento de dados
* Organização de informações
